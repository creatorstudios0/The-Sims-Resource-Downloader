# CreatorStudios Sims 4 Suite v2.2.0

The Midnight Gaming overhaul is available in Sims 4 Mod Library 2.2.0 for 64-bit Windows. This release also includes the portable Console 1.1.0 ZIP and a SHA-256 manifest for both downloads.

## What changed

- The dashboard brings together installed mod counts, a filterable storage breakdown, library health, patch readiness, backups, active transfers, and recent activity. The session notification center keeps messages available after pop-ups fade.
- The library adds a compact view alongside list and thumbnail grid views, plus file type and status filters, creator sorting, an inspector, and right-click actions. Save, rename, and edit profiles and collections to organize mod groups.
- The console supports text and severity filters, color-coded levels, and copying the visible log. Ctrl+K opens the command palette, Ctrl+F focuses the current search field, and Alt+1 through Alt+7 switch pages.
- The desktop uses Inter, Lucide icons, original artwork, three dark themes, and configurable density. Animated switches and notification transitions respect the motion preference.

## Upgrade

Download and run the new desktop EXE. Desktop settings and library records live separately from the executable. For the console, extract the ZIP to a separate folder and retain your existing config, session, saved queue, and downloads.
